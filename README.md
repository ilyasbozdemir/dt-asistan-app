# ⚖️ TEMİN 360 (Kamu Harcama, İhale, Doğrudan Temin ve Hakediş Yönetim Sistemi)

> **"Kamu Harcamalarına, İhale, Doğrudan Temin ve Hakediş Süreçlerine Tam
> Hâkimiyet."**

**TEMİN 360**, kamu kurumları (Belediyeler, Bakanlıklar, Üniversiteler, İller Bankası ve Özel Bütçeli İdareler) için **4734 Sayılı Kamu İhale Kanunu**, **4735 Sayılı Kamu İhale Sözleşmeleri Kanunu** ve **5018 Sayılı Kamu Malî Yönetimi ve Kontrol Kanunu** standartlarına tam uyumlu, **tamamen açık kaynak kodlu** bir kurumsal otomasyon süitidir.

💡 **Mevzuata Uygun Esnek & Özelleştirilebilir Şablonlar:**
Sistemdeki tüm resmi evrak ve tutanak şablonları açık kaynaklı ve modülerdir. Değişen kamu ihale mevzuatına ve kurumunuzun özel yönergelerine göre şablon metinlerini kolayca özelleştirebilir, dosya verilerini şablonlara bağlayarak tek tıkla baskıya hazır, barkodlu ve resmi formatta **PDF / Belge** çıktıları üretebilirsiniz.

## 🏛️ Kapsanan Temel Kamu Süreçleri

### 1. 🏗️ Yapım İşleri & Hakediş Yönetimi (İLBANK & ÇŞB Uyumlu)

- **Anahtar Teslimi Götürü Bedel (ATGB):** İş grupları bazında %100 toplam
  pursantaj tablosu ve dönemlik fiziki ilerleme girişi.
- **Birim Fiyatlı İhaleler:** Metraj cetvelleri ve Yeşil Defter kümülatif
  takibi.
- **Fiyat Farkı:** Fiyat Farkı Kararnamesi ve TÜİK endeks katsayılarına göre
  otomatik hesaplama.
- **Resmi Dizi Pusulası:** Ön Kapak, Dizi Pusulası, Yapılan İşler Listesi,
  İcmal, Kesintiler (%5 Stopaj, %0.948 Damga Vergisi, Avans Mahsubu) ve Arka
  Kapak.

### 2. ⚡ Doğrudan Temin Süreçleri (4734 KİK Md. 22/a-d)

- Lüzum Müzekkeresi ve İhtiyaç Talep Formu.
- Yaklaşık Maliyet Cetveli ve Fiyat İsteme Mektupları.
- Piyasa Fiyat Araştırma Tutanağı ve Karşılaştırmalı Fiyat Cetveli.
- Doğrudan Temin Onay Belgesi ve Sözleşme Taslakları.
- Klasör Sırtlığı ve İndeks Baskıları.

### 3. 📦 Mal Alımı & Taşınır Mal Yönetimi

- Teknik Şartname Hazırlama.
- Muayene ve Kabul Komisyonu Tutanağı.
- Taşınır İşlem Fişi (TİF) ve Ambar Stok Girişi.
- Sevk İrsaliyesi, Fatura ve Garanti Belgesi Arşivleme.

### 4. 📋 Hizmet Alımları & Puantaj Takibi

- Personel Çalışma Puantaj Çizelgeleri ve Araç/İş Makinesi Saat Takibi.
- Barkodlu SGK Prim Hizmet Listesi ve SGK/Vergi Borcu Yoktur Doğrulaması.
- Aylık Hizmet Kabul Tutanağı ve Vezne Ödeme Emri Müzekkeresi.

## 📂 Monorepo Dizin Yapısı

- **[`apps/app-desktop`](./apps/app-desktop):** Electron + React 19 + TypeScript + TanStack Router + Tailwind CSS + SQLite masaüstü uygulaması.
- **[`apps/app-web`](./apps/app-web):** Sunucu tarafı veri senkronizasyonu ve Next.js API katmanı.
- **[`apps/app-landing`](./apps/app-landing):** Tanıtım ve dokümantasyon web sayfası.
- **[`packages/document-templates`](./packages/document-templates):** Mevzuata uyarlanabilir, dinamik resmi evrak ve tutanak şablonları motoru (`@temin360/document-templates`).
- **[`packages/pdf-generator`](./packages/pdf-generator):** Yüksek performanslı sunucu ve masaüstü PDF derleyicisi (`@temin360/pdf-generator`).
- **[`packages/database`](./packages/database):** Veritabanı şemaları, SQLite ve Supabase migrasyonları (`@dt/database`).

## 🚀 Hızlı Başlangıç

Projeyi yerel ortamınızda çalıştırmak için:

```bash
# 1. Bağımlılıkları yükleyin
pnpm install

# 2. Masaüstü uygulamasını geliştirme modunda başlatın
pnpm dev:desktop
```

## 🛠️ Monorepo Komutları

| Komut                | Açıklama                                                 |
| :------------------- | :------------------------------------------------------- |
| `pnpm dev:desktop`   | Masaüstü uygulamasını (Electron) geliştirme modunda açar |
| `pnpm dev:web`       | Web sunucusunu geliştirme modunda açar                   |
| `pnpm build:desktop` | Masaüstü uygulamasının production derlemesini alır       |
| `pnpm build:web`     | Web sunucusunun production derlemesini alır              |
| `pnpm typecheck`     | TypeScript tip kontrollerini çalıştırır                  |
| `pnpm format`        | Prettier kod formatlamasını çalıştırır                   |
| `pnpm lint`          | ESLint denetimini çalıştırır                             |
